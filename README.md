# Seunghyun Yoo's Personal Website

Personal academic website built with Jekyll and hosted on GitHub Pages.

🌐 **Live Site**: [https://carteryoo.github.io](https://carteryoo.github.io)

### Local Development
```bash
# Install dependencies
bundle install

# Run local server
bundle exec jekyll serve
```

### Editing
- Profile, links, and CV: `_data/main_info.yaml`
- About, education, and teaching: `_data/content.yaml`
- Publications: `_data/publications.yaml`
- Projects: `_data/projects.yaml`
- Experience timeline: `_data/experience.yaml`

Based on [Dasol Choi's template](https://github.com/Dasol-Choi/dasol-choi.github.io).
